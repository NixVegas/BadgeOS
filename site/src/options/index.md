# Options

These are the NixOS options that BadgeOS declares, generated from the modules in the
repository every time this site is built. Each entry shows the option's type, its default,
an example if there is one, and the file that declares it.

To find an option by name or by what it does, use the [options search](search.md). The
search button at the top of every page (or the <kbd>S</kbd> key) searches the whole site,
including these pages.

| Group | Options |
|---|---|
@OPTIONS_OVERVIEW@

Each group is one page, with all the options under one name, such as `badge.bling`.
The same data is also available as [`options.json`](options.json), in the same format as
the NixOS manual's `options.json`, for use with other tools.
